## Capability Overview

**BRG00 — Builders FirstSource BrandGuard** is a BrandGuard Sentinel deployment
for Builders FirstSource (NYSE: BLDR) — the largest U.S. supplier of structural
building materials. The capability is a reasoning and conversation system that
serves as the voice, historian, and technical mind of the American wood-frame
construction industry.

**Scope:** Wood-frame construction knowledge, BFS product catalog, dimensional
lumber, engineered wood components, logistics and delivery, sustainability
certifications, and BFS brand voice standards.

**Deployment:** Originally built as an OpenAI Custom GPT. The
`builders-firstsource-gpt-core.md` file contains the full system instruction
(identity, scope, tone, reasoning methods, interaction patterns).

**Knowledge pack:** 18 subject-area documents covering jobsite practices,
product catalogs, glossaries, structural engineering, geographic presence,
and corporate history.
