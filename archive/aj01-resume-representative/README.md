This archive contains the original knowledge pack and supporting documents for
the **AskJamie™ Résumé Representative** capability (`aj01`). This was the
first AskJamie capability, focused on dynamic resume hybridization, cover
letter generation, HR intelligence, and career market-value guidance.

This content was developed as a Custom GPT knowledge pack and has not yet been
structured into the formal AskJamie capability architecture (`skill/`,
